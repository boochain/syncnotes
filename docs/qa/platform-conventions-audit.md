# 全平台交互规范自查（Android / Windows / Linux）

分支：`fix/android-back`　日期：2026-10-18
状态说明：✅ 已符合 / 🔧 本次修复 / ⏳ 待办（已知问题，未在本次完成） / ❓ 未验证（需真机）

参考规范：
- Android：Material 3（m3.material.io）、Android 开发者文档《返回导航 / 预测性返回》《全面屏 edge-to-edge》《通知运行时权限》《触摸目标 48dp》
- Windows：Fluent Design / Win32 UX 指南（键盘快捷键、通知区域图标、窗口管理）
- Linux：GNOME HIG（键盘、对话框、通知、托盘/后台应用）

## Android

| 项目 | 规范要求 | 现状 / 处理 | 状态 |
|---|---|---|---|
| 系统返回键 | 先关临时界面，再逐级返回上一页；不能直接退出（Android 返回导航） | 原来根 Navigator 只有一个路由，返回直接结束 Activity。新增 `RootBackScope`：对话框 → 抽屉 → 底部菜单/弹出菜单 → 页面/文件夹/设置 → 首页搜索/筛选 → 宽屏页面回收件箱 | 🔧 |
| 根页面双击退出 | 根页面误触保护：提示"再按一次退出"，2 秒内再按退出 | `BackToExit`，提示复用 `showToast`（在发送栏上方），2 秒后重置 | 🔧 |
| 编辑器返回 | 返回不能丢失编辑 | 页面：先收起焦点/斜杠菜单/工具栏，再返回；标题防抖未到时立即保存。旧笔记编辑器 `PopScope` 已在返回时保存 | 🔧 |
| 登录页返回 | 同根页面 | 双击退出 | 🔧 |
| 预测性返回 | `android:enableOnBackInvokedCallback="true"` + `PopScope`（不用已弃用的 `WillPopScope`） | 已开启；根页面始终由 Flutter 处理返回 | 🔧 ❓（Android 14+ 动画需真机确认） |
| 状态栏/导航栏 | edge-to-edge，透明系统栏，图标明暗跟随主题 | 原来没有 AppBar 的首页依赖默认样式，深色模式下状态栏图标可能看不清。现在启用 edge-to-edge，`AnnotatedRegion` 按主题设置图标明暗 | 🔧 |
| 安全区 | 内容避开刘海、手势条 | 首页 `SafeArea(bottom:false)` + 发送栏 `SafeArea(top:false)`；其它页 AppBar 处理顶部 | ✅ |
| 输入法避让 | 输入栏在键盘上方 | `adjustResize` + Scaffold `bottomNavigationBar` 跟随 viewInsets | ✅ ❓ |
| 滚动收起键盘 | 拖动列表收起键盘 | 收件箱/文件夹列表、设置页 `keyboardDismissBehavior.onDrag` | 🔧 |
| 按压反馈 | Material 水波纹 | 原来全局 `NoSplash`，Android 没有任何按压反馈。现在触屏平台用 `InkRipple`，桌面仍用悬停高亮 | 🔧 |
| 悬停态不粘住 | 触屏上不应出现/残留悬停高亮 | 所有自定义 `MouseRegion` 悬停（卡片、筛选标签、侧边栏行、页面头部、块行、斜杠菜单）只接受鼠标指针 `isMouseHover` | 🔧 |
| 长按菜单 + 触感 | 长按出菜单并有触感反馈 | 卡片长按加 `Feedback.forLongPress` | 🔧 |
| 触摸目标 48dp | 可点区域 ≥ 48dp | 主题 `materialTapTargetSize: shrinkWrap`，顶栏图标按钮 32×32。改动会影响全部布局/尺寸测试 | ⏳ |
| 下拉刷新 | 有 | 收件箱 `RefreshIndicator` | ✅ |
| 越界滚动 | Android 拉伸效果（不是 iOS 回弹） | M3 默认 stretch，没有覆盖 ScrollBehavior | ✅ |
| 文本选择/复制 | 消息可选可复制 | 点击消息复制；笔记预览 `selectable` | ✅ |
| 中文输入法组字 | 不丢字、光标不乱跳 | 编辑器控制器有组字保护（已有测试） | ✅ ❓ |
| 分享进/出 | 系统分享 | 未实现 share intent | ⏳ |
| 通知权限 | Android 13+ 运行时请求 POST_NOTIFICATIONS，最好先说明用途 | 启动时直接请求，没有说明 | ⏳（缺少说明文案） |
| 通知渠道 | 分渠道 | "新内容"、"后台同步"两个渠道 | ✅ |
| 点击通知 | 打开对应内容 | 原来点击只打开应用。现在 `Notifier.opened` → 外壳打开对应块（含冷启动） | 🔧 |
| 重复通知 | 开前台服务时不重复 | 前台服务负责时主进程不再通知 | ✅ |
| 生命周期 | 回到前台重连；旋转/进程被杀不丢数据 | `resumed` 时重连；本地缓存 + 待发送队列持久化 | ✅ ❓ |
| 平板/分屏/横屏 | 自适应 | ≥720 宽屏侧边栏布局；响应式测试 13 种尺寸 | ✅ |
| 深色模式 | 跟随系统 | 默认"跟随系统"，启动页有 values-night | ✅ |
| 字号 200% | 不溢出 | 响应式测试覆盖到 1.3×；200% 未测 | ⏳ |
| 自适应图标 | adaptive icon | 只有 mipmap PNG，没有 adaptive icon | ⏳ |
| 应用名 | 中文环境显示 | "SyncNotes" 品牌名，没有中文名 | ⏳（需产品决定） |

## 桌面（Windows / Linux）

| 项目 | 规范要求 | 现状 / 处理 | 状态 |
|---|---|---|---|
| Esc 关闭对话框/菜单/弹层 | 是 | Flutter 默认；斜杠菜单 Esc；首页搜索框 Esc 关闭 | ✅ 🔧 |
| Enter 发送 | 单行 Enter 发送 | 发送栏 `TextInputAction.send` | ✅ |
| 标准快捷键 | Ctrl+C/V/X/Z/Y/A，Ctrl+F 查找，Ctrl+, 设置 | 编辑器 Ctrl+Z/Y/B/I/E；新增 Ctrl+F（快速查找）、Ctrl+,（设置）；Ctrl+N / Ctrl+W 没有 | 🔧 / ⏳ |
| 系统返回（桌面无） | 新的返回处理不影响 Esc | 桌面不会收到 popRoute；Esc 行为不变 | ✅ |
| 右键菜单 | 有 | 卡片右键 = 长按菜单 | ✅ |
| 悬停/光标 | 可点处显示手型 | 卡片、筛选标签、拖动手柄有 | ✅ |
| 窗口最小尺寸 | 有 | 340×420 | ✅ |
| 记住窗口位置/大小 | Win32/GNOME 惯例 | 小窗固定在右下角（托盘弹窗式设计）；展开大小不记忆 | ⏳ |
| 关闭到托盘 | 行为明确、可配置 | 有托盘时关闭=隐藏；没有托盘时关闭=退出。不能配置 | ⏳ |
| 托盘菜单 | 显示/退出 | 显示窗口（未读数）/ 退出 | ✅ |
| 单实例 | 第二次启动聚焦已有窗口 | `SingleInstance` | ✅ |
| 窗口标题/任务栏图标 | 有 | 标题 SyncNotes | ✅ |
| 桌面通知 | Windows Toast / Linux D-Bus | 有；点击通知现在会打开对应块并显示窗口 | 🔧 |
| HiDPI | 125/150/200% | 响应式测试 1.0/1.3；真机未测 | ❓ |
| 拖放文件 | 拖入上传 | 未实现 | ⏳ |
| 中文输入法候选窗位置 | 跟随光标 | Flutter 引擎负责；未在真机验证 | ❓ |
| 自启动 | 开关有效 | 已有测试 | ✅ |
