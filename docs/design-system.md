# SyncNotes 设计系统（v0.4）

v0.4 起**不再自创设计**，而是尽量照搬成熟产品的数值：

| 来源 | 用在哪里 | 怎么用 |
| --- | --- | --- |
| **AppFlowy**（开源 Flutter 版 Notion，AGPL-3.0） | 侧边栏宽度与行高、页面头部（封面 / 图标 / 标题）、编辑器间距、字阶、圆角与间距刻度 | 只读了它的源码并记下**数值和布局方式**，在我们自己的代码里重新实现；没有复制任何源代码 |
| **Notion** | 整体布局：平铺侧边栏 + 细分隔线 + 内容区；页面图标压住封面下沿；斜杠菜单；灰色提示框；视图标签 | 布局与交互模式 |
| **Apple HIG / Apple Design Resources** | 颜色（系统灰阶 + systemBlue）、开关、分段控件、分组表单、弹簧动画 | 直接使用公开规范中的颜色值与控件尺寸 |

所有令牌集中在 `app/lib/ui/ds.dart`，主题在 `app/lib/ui/theme.dart` 中把 Material 组件全部映射到这些令牌上。业务代码里**不允许**再写裸颜色值、裸字号或随意的高度。

## 1. 高度刻度（同一行的元素必须同高、垂直居中）

| 令牌 | 值 | 用途 | 参考 |
| --- | --- | --- | --- |
| `Sizes.compact` | 28 | 筛选标签、页面头部操作、卡片“更多”按钮、代码块顶栏 | AppFlowy 小按钮 |
| `Sizes.control` | 32 | 侧边栏行、菜单项、图标按钮、工具栏按钮、分段控件、搜索框 | AppFlowy `workspaceSectionHeight 32` / 视图行 30 |
| `Sizes.input` | 36 | 输入框、发送栏（+ / 输入框 / 发送）、主要按钮 | HIG 常规控件 |
| `Sizes.bar` | 44 | 顶栏、筛选行、底部弹窗菜单行、设置行、登录表单行与按钮、斜杠菜单行、快速查找行 | AppFlowy `topBarHeight 44`；HIG 最小点击区域 44 |
| `Sizes.listRow` | 56 | 收件箱行（两行：标题 + 摘要）、带说明的设置 / 菜单行 | AppFlowy 移动端视图行 48–56 |

规则：
- 同一行里的元素使用同一个高度并垂直居中（例：发送栏三件套都是 36；顶栏按钮 32 居中于 44 高的栏）。
- 列表行使用固定高度（收件箱 56、侧边栏 32），所有类型（消息 / 页面 / 文件 / 文件夹 / 笔记）完全一致；文件夹不再更高。
- 含文字说明的行用**最小**高度，字号放大到 1.3 倍时只增高，不溢出。
- 对应测试：`test/alignment_test.dart`。

## 2. 字体与字阶

- 唯一字体栈：系统 UI 字体 → `Noto Sans CJK SC` / `PingFang SC` / `Microsoft YaHei` → emoji 字体。等宽字体只用于代码。
- 界面字阶只有 **5 个字号、3 个字重**（AppFlowy 正文 14/20、说明 12/18 的取值）：

| 令牌 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `AppText.caption` | 12 / 16 | 400 | 时间、摘要、说明、分组标题 |
| `AppText.body` | 14 / 20 | 400 | 正文、菜单、输入 |
| `AppText.bodyStrong` | 14 / 20 | 500 | 选中项、按钮 |
| `AppText.title` | 16 / 22 | 600 | 顶栏标题、弹窗标题 |
| `AppText.headline` | 20 / 28 | 600 | 登录页标题 |

- 所有标题统一 600 字重（不再混用 700 / 800）。
- 编辑器字阶（AppFlowy 编辑器：正文 16、行高 1.5，标题 +14/+8/+4）：页面标题 36/44，H1 30/38，H2 24/32，H3 20/28，正文 16/24，代码 14/20；全部标题 600。
- **emoji 对齐**：`Emoji` 组件把 emoji 放进固定方框（行高 1.0、关闭字号缩放、强制 strut），侧边栏 20、卡片 20、页面图标 60，emoji 的基线和大小与文字行对齐，不再偏低、忽大忽小。

## 3. 颜色

一套中性灰（Apple 系统灰阶）加**唯一强调色 systemBlue**。没有渐变背景，没有灰蓝封面，也没有米色提示框。

| 令牌 | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| `bg` | #FFFFFF | #1C1C1E | 内容区背景（纯色） |
| `sidebar` | #F5F5F7 | #232325 | 侧边栏 |
| `elevated` | #FFFFFF | #2C2C2E | 浮层：菜单、弹窗、底部弹窗 |
| `fill` | #F2F2F7 | #2C2C2E | 输入框、代码块、提示框、行内代码 |
| `hover` / `selected` | 黑 4% / 7% | 白 6% / 10% | 悬停与选中都是中性叠加，不铺强调色 |
| `separator` | #E5E5EA | #38383A | 细分隔线 |
| `text` / `text2` / `text3` | #1D1D1F / #6E6E73 / #8E8E93 | #F5F5F7 / #AEAEB2 / #8E8E93 | 三级文字 |
| `accent` | #007AFF | #0A84FF | 唯一强调色：主按钮、链接、焦点、未读点 |
| `danger` / `success` / `warning` | systemRed / Green / Orange | 同左（深色版） | 只用于状态 |

- 块类型图标统一用 `text2`，不再按类型上色（消息蓝、文件夹黄……）。
- 封面只有 4 个安静的纯色（浅灰 / 浅蓝 / 石板 / 石墨），旧版渐变封面键会自动映射。
- 液态玻璃只用于**浮动界面**（斜杠菜单、快速查找、格式工具栏），并且效果极淡（94% 不透明、无色散）；背景是纯色。

## 4. 圆角、间距与图标

- 圆角：4（行内小件）/ 6（行、标签、按钮）/ 8（输入框、代码块、提示框、卡片）/ 12（菜单、浮层、表单）/ 16（弹窗、底部弹窗）。发送栏的输入框和按钮用高度的一半（胶囊）。
- 间距：4 / 6 / 8 / 12 / 16 / 20 / 24 / 32（AppFlowy 的间距刻度）。
- 图标：只用一套 **CupertinoIcons**（SF Symbols 风格），尺寸 16（行内）/ 20（按钮）。拖动手柄是自绘的六点图形。

## 5. 布局（Notion / AppFlowy）

- 宽屏（≥ 900）：侧边栏 260 宽、平铺、右侧 1px 分隔线；内容区纯色背景。窄屏：侧边栏进抽屉。
- 侧边栏：用户行 44，搜索 / 收件箱 / 设置行 32，“页面”分组标题 32，页面树每级缩进 16，展开箭头 20。
- 页面：封面 240（窄屏 160），图标 60，一半压在封面下沿，图标 / 标题 / 正文左对齐；正文最大宽度 900。
- 收件箱：顶栏 44 → 筛选行 44（标签 28）→ 56 高的两行列表 → 发送栏。

## 6. 控件

- 开关：HIG 开关（开 = systemGreen）。分段控件：HIG 样式，32 高、选中段为浮起的白色胶囊。
- 按钮：主要 36（实心强调色），次要 32（文字按钮），危险操作用红色实心按钮。
- 菜单项 32；底部弹窗菜单行 44（带说明 56）；斜杠菜单 / 快速查找行 44。
- 提示条（SnackBar）：浮动、圆角 8；浅色模式深底白字。

## 7. 响应式

`test/responsive_test.dart` 在 320 / 360 / 390 / 430 / 600 / 800 / 1024 / 1280 / 1600 / 1920 宽、托盘小窗（400×640）、手机横屏（844×390、740×360）、浅色 / 深色、1.0 / 1.3 倍字号下打开收件箱、长标题页面和快速查找，断言没有任何溢出。测试数据包含超长中英文标题、无空格长链接和长文件名。
