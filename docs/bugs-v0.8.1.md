# v0.8.1 Bug 清单

v0.8.0 发布后用户反馈「各端 bug 太多」。这份清单记录 v0.8.1 主动排查出的问题：现象、影响、原因、修复、验证方式。
设计层面的问题（层级、动画、透明度、规范对齐）单独记在 [design-audit-v0.8.1.md](design-audit-v0.8.1.md)。

排查方式：Linux 桌面版在 Xvfb 下对本地服务端实跑并逐帧截图；网页版用 Playwright 跑真实端到端；服务端与客户端代码审读；补充单测与集成测试。

## 服务端

### S1 登录没有失败次数限制（可在线暴力猜密码）
- 现象：`/api/login` 可以无限次尝试密码。恢复码接口有限流，登录没有。
- 影响：公网部署时账号密码可被在线枚举。
- 原因：限流器只接在 `/api/recover`、`/api/recovery-code`、`/api/change-password`。
- 修复：新增 `login_limiter`（同一用户名 15 分钟内 10 次、同一 IP 60 次），超出返回 429「密码错误次数过多，请 15 分钟后再试」；登录成功清零该用户计数。
- 验证：`tests/recovery_tests.rs::login_is_rate_limited_per_user`。

### S2 同名并发注册返回 500
- 现象：两个设备同时注册同一个用户名，后到的一个收到「服务器内部错误」。
- 原因：先查后插，插入撞 UNIQUE 约束时被当成内部错误。
- 修复：UNIQUE 冲突映射为 409「用户名已存在」。
- 验证：代码路径审读 + 现有注册测试。

### S3 恢复备份时把所有附件读进内存
- 现象：备份里附件总量接近几个 GB 时，服务器恢复会内存暴涨，小内存 VPS 直接被 OOM 杀掉，账号恢复失败。
- 原因：`open_archive` 把每个附件 `read_to_end` 进 `HashMap<String, Vec<u8>>`，再逐个写盘。
- 修复：解析阶段只记录「附件 id → zip 条目名」，还原时逐条流式解压到暂存目录（256 KB 缓冲），边写边算 SHA-256。
- 验证：`tests/backup_tests.rs` 全部通过；新增 `restore_maps_attachments_with_same_id_prefix`。

### S4 恢复时附件可能对错文件
- 现象：两个附件 id 前 8 位相同（导出文件名就是 `files/{id前8位}-{文件名}`）时，恢复后两个文件块可能指向同一份内容，另一份丢失。
- 原因：用「条目名包含 id 前 8 位」做模糊匹配，取第一个命中。
- 修复：先按导出时的精确文件名匹配，其次 `files/{完整id}`，最后才按前缀。
- 验证：`restore_maps_attachments_with_same_id_prefix`（先写入 b.txt 再写 a.txt，旧逻辑会把 B 的内容给 A）。

### S5 zip 条目声明大小不可信
- 现象：恶意构造的 zip 可以声明很小的 `blocks.json` 大小，实际解压出很大的内容。
- 修复：读取 JSON 条目时按上限 `take(max+1)` 截断并校验实际长度。
- 验证：代码审读；现有路径穿越 / 坏包测试仍通过。

### S6 文件接口审查（无需修改）
- 审查项：路径穿越、跨用户访问、分片续传。
- 结论：`file_id` / `upload_id` 只接受 16 进制与 `-`（`safe_id`），所有路径都拼在令牌解析出的用户目录下，不能访问他人文件；分片偏移量必须连续（大于当前长度返回 409），完成时整文件 SHA-256 校验，不符即删除暂存件；超过 24 小时的暂存分片自动清理。

## 同步与数据（App + 网页）

### D1 多设备同时改同一块，后写者静默覆盖先写者（LWW 丢数据）
- 现象：手机离线改了一条笔记，电脑同时也改了；手机联网后，手机上的修改直接消失，没有任何提示。
- 影响：用户以为保存了的内容丢失，是最严重的一类数据问题。
- 原因：同步是「最后写入者胜」，收到更新版本时直接替换本地，还把本地待上传的修改从发件箱里删掉。
- 修复：本地有未上传修改且被更新的远端版本覆盖时，把本地版本另存为同级的「标题（冲突副本 月/日 时:分）」，再接受远端版本。App 与网页逻辑一致。
- 验证：`app/test/sync_client_test.dart` 两条冲突用例；`web/test/engine.test.ts` 两条冲突用例。

### D2 网页版重连补同步时弹一堆「新消息」提示
- 原因：补同步阶段收到的每个旧块都被当成「新建」。
- 修复：补同步（catching up）期间不判定为新消息。
- 验证：`web/test/engine.test.ts`。

### D3 新建任务后直接返回，各设备都多出一条「未命名任务」
- 现象：点「新建任务」，什么都没填就返回，任务列表、日历、其它设备上都多出一条空任务。
- 原因：打开编辑页之前就创建并同步了任务。
- 修复：新建流程打开的编辑页带 `discardIfEmpty`，返回时如果标题为空、没有日期 / 备注 / 进度项 / 子任务、状态与优先级都是默认值，就彻底删除（与 Things、Todoist 丢弃空草稿一致）。已有任务不受影响。
- 验证：`task_dashboard_widget_test.dart`「new task left empty is discarded on back」。

### D4 夏令时地区日期差一天
- 现象：在有夏令时的时区（欧美），跨过夏令时结束那天，「每天 / 每周」重复、订阅续费日、倒数日、提前 N 天提醒会重复同一天或跳一天，提醒时间偏 1 小时。
- 原因：日期加减用「本地午夜 + N×24 小时」，夏令时切换当天只有 23 / 25 小时。
- 修复：`CivilDate.addDays / differenceInDays` 改为 UTC 日期算术；提醒、本周起始日、「N 天内到期」都用日历日构造。网页版本来就用 UTC，无需修改。
- 验证：新增 `test/civil_date_dst_test.dart`，CI 额外以 `TZ=America/New_York` 运行日期相关测试。

### D5 任务进度可能显示 NaN%
- 原因：同步来的进度项权重或手动进度是 NaN / Infinity 时没有过滤。
- 修复：非有限数权重跳过，手动进度非有限数按 0。

## App（Android / Windows / Linux）

### A1 页面切换时新旧两页文字叠在一起
- 现象：打开设置、回收站等页面时，动画过程中上一页的文字透过新页显示出来，两层文字重叠。开启玻璃效果时最明显。
- 原因：页面路由用的是 `PageRouteBuilder`，首页收不到 `secondaryAnimation`，被覆盖时既不移动也不裁剪；玻璃页面背景透明，于是两页文字重叠。
- 修复：路由统一为 `MaterialPageRoute` + 自定义覆盖式转场：新页从右侧推入，旧页同步视差左移并在新页左边缘处裁掉，附边缘阴影；返回时完全对称。
- 验证：`test/route_transition_test.dart`（推入、返回过程中逐帧检查两页不重叠）；录屏截图 `docs/design-audit/before-push-overlap.png` → `after-push-no-overlap.png`、`after-pop-exit.png`。

### A2 宽屏切换分区时内容区闪白
- 原因：切换动画只有新内容淡入，没有旧内容退出，且两段时间重叠。
- 修复：改为 Material 3 Fade-through（旧内容前 35% 淡出，新内容后 65% 淡入并 0.96→1 缩放）。
- 验证：`test/motion_dpi_test.dart`；`before-wide-switch-blank.png` → `after-wide-switch.png`。

### A3 列表删除没有退出动画
- 修复：块列表删除时淡出并收起高度；左滑删除的条目不再重复播放。

### A4 返回按钮显示成「楼房」形状
- 原因：Material 返回图标在当前字体下渲染异常。
- 修复：返回 / 关闭 / 侧栏统一用 Cupertino 图标。
- 验证：`before-back-glyph.png`。

### A5 玻璃效果下文字对比度不足
- 现象：浅色 + 玻璃背景时，次要文字、占位文字看不清。
- 修复：玻璃模式下次要 / 三级文字、强调色、危险色加深到 WCAG AA（4.5:1）；预设背景着色从 42% 降到 10%（浅色）/ 18%（深色）。
- 验证：`before-placeholder-contrast.png`。

### A6 日历页标题和选中样式
- 修复：标题固定为「日历」；日期选中改为 28px 圆形（今天强调色，选中为文字色），去掉灰色方块；补充无障碍标签。

### A7 日历提醒只在应用打开时生效
- 现象：Android 上关掉应用后，日历事件不提醒。
- 修复：提醒仍由 SyncNotes 自己发送（不依赖系统日历、不申请日历权限），Android 额外用本地通知预约未来 48 条提醒（非精确闹钟，不申请 `SCHEDULE_EXACT_ALARM`），开机后自动恢复；已提醒记录持久化，避免重启后重复提醒。

### A8 任务页细节
- 主按钮（新建）改为实色强调色 + 白色图标，不再半透明发灰。
- 没有任何任务时不再显示整行「0」统计卡和空进度环；统计数为 0 时用中性灰，只有真有逾期 / 风险时才显示红色 / 橙色。
- 任务视图筛选改用与首页相同的胶囊样式。
- 验证：`task_dashboard_widget_test.dart`。

## 网页版

### W1 恢复码弹窗点背景就关闭
- 现象：注册后显示恢复码的弹窗，点外面就关掉了，用户可能还没抄下恢复码。
- 修复：只能点按钮关闭；补充 `role=dialog`。

### W2 补充真实端到端测试
- 新增 Playwright：注册 / 刷新保持登录 / 发消息；两个浏览器实时同步新建与删除、回收站；任务与日历页面；密码错误提示。CI 中先编译服务端再运行。
