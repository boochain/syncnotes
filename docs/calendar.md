# SyncNotes 日历

本文是 `feature/calendar` 的设计说明。实现以它为准。基准版本：v0.7.2（`9890161`）。

## 调研后融入的能力

用户明确要求：会员订阅（起止日期、自动续费 / 单月 / 单季度 / 单年等可扩展周期）、重要日期、倒数日。

对照主流日历（Google Calendar、Fantastical）、订阅管理（Bobby、Orbit、Subwise）和倒数日应用（倒数日 Days Matter、The Days、DaysTill、SoFar）后，把下面这些用户没点名、但属于主流体验的部分一并做进来：

- **年 / 月 / 周 / 议程**四种视图。月视看全貌，周视看这一周，年视跳月份，议程是按时间排的清单（含即将到期的续费和倒数）。一周从周一开始（ISO-8601 / 国内习惯）。
- **全天与跨天**。全天事件按公历日期存储，避免时区把“那天”推到前一天。带时刻的事件可跨午夜。
- **时区**。每条记录保存 IANA 时区，默认设备所在时区（中国常用 `Asia/Shanghai`）。全天事件不按时区换算日期。
- **续费提醒与下次扣款日**。按周期和起始日推算下次扣款；月底日期对不齐时落到该月最后一天（1 月 31 日 + 1 个月 = 2 月 28/29 日）。可设提前提醒（当天、1 / 3 / 7 / 30 天，也可自定义）。试用结束单独提醒。
- **费用与币种**。金额 + 币种（CNY / USD / EUR / JPY / HKD / TWD / GBP 等，可手填）。同一币种汇总本月应付、月均、年均。不自动拉汇率，避免把账算错；多币种分开显示。
- **状态**：使用中、试用、已暂停、已取消、已到期、待续。暂停只停提醒和汇总，不删记录。非自动续费到期后标成“待续”。
- **重要日图针**。重要日期和置顶的倒数日在月视格子里用图针标记，一眼能看见。
- **倒数与正数**。未来显示“还有 N 天”，当天“就是今天”，过去“已经 N 天”。生日 / 纪念日可按年循环，并显示即将到来的岁数。
- **分类、颜色、备注、置顶、管理页链接**（订阅可选填官网或取消入口）。
- **即将到期条**：首页顶部列出近 7 天要扣款的订阅和近 14 天的倒数日。

未纳入本版、列在文末：农历、桌面小组件、自然语言输入、汇率换算、银行导入、双时区时间轴。

## 数据模型

日历条目是一种同步块：`kind = "calendar"`。服务器本来就把未知 `kind` 当不透明 JSON 存下来，旧客户端能同步、进回收站、恢复，只是列表里显示“未知类型”。协议版本仍为 3，不升号。健康检查的 `features` 增加 `"calendar"`，方便以后探测，旧客户端会忽略这个字段。

### 载荷（`payload`）

所有日期为公历 `YYYY-MM-DD`（全天按日期，不转成时间戳）。可选时刻为 `HH:MM`（24 小时）。未识别的字段原样保留，便于以后加字段。

```json
{
  "schema": 1,
  "role": "event | subscription | important | countdown",
  "all_day": true,
  "start_date": "2026-12-01",
  "end_date": "2026-12-01",
  "start_time": null,
  "end_time": null,
  "timezone": "Asia/Shanghai",
  "notes": "",
  "color": "orange",
  "pinned": false,
  "category": "娱乐",
  "reminders": [0, 1, 7],
  "recur": { "freq": "none | daily | weekly | monthly | yearly", "interval": 1, "until": null },
  "billing": {
    "cycle": "weekly | monthly | quarterly | yearly | custom | once",
    "interval": 1,
    "interval_unit": "day | week | month | year",
    "auto_renew": true,
    "amount": 18.0,
    "currency": "CNY",
    "status": "active | trial | paused | cancelled | expired | pending",
    "trial_ends": null,
    "last_paid": null,
    "url": ""
  },
  "count": { "mode": "both | countdown | countup", "repeat_yearly": false, "show_age": false }
}
```

- `role=event`：普通日程，可带时刻、可跨天、可重复。
- `role=subscription`：会员订阅。`cycle` 是周期（单周 / 单月 / 单季度 / 单年 / 自定义 / 一次性），`auto_renew` 是是否自动续费，两者分开，避免把“自动续费”和“按月”揉成一个枚举。`interval` + `interval_unit` 用于“每 2 个月”“每 4 周”这类自定义周期。
- `role=important`：重要日期。默认为全天、可按年重复，月视带图针。
- `role=countdown`：倒数日。默认开启正数；可按年重复（生日）。

`title` 使用块自带的标题字段。`viewed_mode` 默认 `global`（看过一处即各处已读，日历提醒不靠未读角标）。删除走现有回收站；日历条目没有子块。

### 客户端原始 kind 保留

旧客户端把不认识的 `kind` 解析成枚举 `unknown`，若再整包回传（例如以后的“一键立即同步”），可能把 `calendar` 写成 `unknown`。本改动在 `Block` 上保留 `kindRaw`，读写都用原始字符串。日历还会把 `kindRaw == "task"` 的块当作只读日程叠加（见下节），即使当前构建没有 `BlockKind.task`。

### 与任务仪表盘的对接（不阻塞任何一方）

日历数据自包自足，不依赖 `feature/task-dashboard`。任务仪表盘若用块类型 `task`（或载荷里带 `start_date` / `due_date` / `end_date` 的同类结构），日历用下面的只读出现（occurrence）接口叠加到格子里，不改任务块：

- 出现记录：`id`、`blockId`、`title`、`date`、`endDate`、`allDay`、`startTime`、`source`（`calendar` 或 `task`）、`role`、`color`、`pinned`。
- 任务在日历上可点开展示摘要，编辑仍回任务页（任务功能合并后再接 `execute`）。
- 任务不进入订阅汇总，也不占用日历的新建入口。

在任务分支合并前，日历单独工作；合并后只要任务块 kind 为 `task` 且日期字段兼容，无需再改协议。

### 与备份 / 立即同步

日历块走同一套 LWW upsert 和离线队列，会进入现有“导出我的数据”和将来的备份包（备份以当前账号可见块为准）。不引入存储加密。

## 界面

- **入口**：只在侧边栏（窄屏即抽屉）增加“日历”一行，放在收件箱和设置之间。不改首页顶栏布局（顶栏由其他分支调整）。
- **不进收件箱**：`kind=calendar` 不出现在收件箱列表，也不计入未读数，避免和消息、笔记混在一起。回收站、快速切换、导出仍然包含它们。
- **页面结构**：顶栏为返回、当前年月、今天、视图菜单（月 / 周 / 年 / 议程 / 订阅 / 倒数）和新建。默认是月历 + 所选日议程；顶部可列出近 7 天续费和近 14 天倒数。月历格子可显示农历（默认开，可在菜单关掉）。点某一天可查看当天条目，长按预填该日期新建。
- **新建**：可先选角色（日程 / 订阅 / 重要日 / 倒数日），再填表。点某一天新建时预填该日期。编辑是独立页面，Android 返回键先关选择器 / 未保存确认，再回到日历，再回到上一页；根页仍是按两次退出。
- **视觉**：使用现有液态玻璃、`AppColors`、高度阶梯 28/32/36/44/56 和圆角令牌。类型色取 HIG 系统色：日程蓝、订阅橙、重要日红、倒数紫。
- **平台**：Android / Windows / Linux 同一套页面；桌面可右键编辑或删除。提醒用已有的本地通知，不依赖付费推送。

## 提醒

本地调度即将发生的提醒（约未来 90 天）。应用回到前台时会重算，避免漏掉。订阅在暂停 / 取消 / 过期后不再提醒。通知点按打开对应条目。Android 使用非精确闹钟，尽量不申请 `SCHEDULE_EXACT_ALARM`。

## 测试要点

- 周期推算：月底、闰年、季度、自定义间隔、自动续费与一次性、过期与待续。
- 倒数 / 正数文案、按年重复的下一个周年。
- 载荷解析保留未知字段；`kindRaw` 往返不被改写成 `unknown`。
- 日历块进回收站并可恢复；不出现在收件箱。
- 服务器接受 `kind=calendar` 并回传原样。
- 界面：月视高亮今天、图针、视图切换、新建订阅后出现在格子和汇总里、Android 返回从编辑页回到日历。
