# v0.8.1 设计审计

对照 Apple HIG、Material 3（M3）、Fluent 2、WCAG 2.2，以及 Notion / Things / Linear 的成熟做法，逐页检查 SyncNotes 的层级、动效、透明度、对比度、点击区域、状态、一致性和功能流程。
每条记录：问题、依据（规范出处）、修复方式、状态、截图。截图都在 [design-audit/](design-audit/)。

检查方法：Linux 桌面版在 Xvfb（1400×900 宽屏、400×860 窄屏）实跑，用 ffmpeg 30fps 录下进入 / 退出动画并抽帧；浅色 / 深色、玻璃开 / 关各看一遍；网页版用 Playwright 截图。

状态：✅ 已修复　🟡 部分修复　⏳ 待修　📝 记录不改（附原因）

## 一、层级（z 轴、信息层级、导航层级）

| # | 问题 | 依据 | 修复 | 状态 |
|---|---|---|---|---|
| H1 | 打开二级页面时上一页文字透过新页面显示，两层文字重叠；被覆盖的页面不后退、不变暗，看不出谁在上层 | HIG *Navigation*：推入页面应完整覆盖并让下层后退；M3 *Motion – Transitions / Shared axis*：前后两层必须有清晰的上下关系 | 路由统一为 `MaterialPageRoute`，覆盖式转场：新页推入，下层同步视差后退并在新页边缘处裁掉，边缘加阴影表现高度 | ✅ `before-push-overlap.png` → `after-push-no-overlap.png` |
| H2 | 恢复码对话框弹出时登录卡片被遮罩压暗，看起来像消失 | M3 *Dialogs*：遮罩只降低背景强调 | 复查：遮罩为标准 54% 黑，登录卡片仍可辨认，属于正常模态层级；不改 | 📝 |
| H3 | 任务页没有任务时依然显示「整体进度 0%」和四个全 0 统计卡，把空状态挤到下面 | M3 *Empty states*：空时只给一个主要引导；HIG *Layout*：最重要的信息放最显眼处 | 没有任务时隐藏概览，只显示空状态和新建按钮 | ✅ |
| H4 | 任务统计数字为 0 时依然用红 / 橙色，制造假警报 | M3 *Color – semantic roles*：错误色只用于真正的错误；Fluent 2 *Color – Status* | 0 用中性灰，大于 0 才用语义色 | ✅ |
| H5 | 日历「新建」按钮半透明，背景复杂时几乎看不到，主操作层级低于普通内容 | M3 *FAB*：FAB 是页面最高强调，实色容器；HIG *Buttons – Prominent* | 全局 FAB 主题：实色强调色 + 白色图标 + 3dp 阴影 | ✅ |
| H6 | 卡片右上角有无说明的小圆点 / 圆圈 | HIG *Icons*：图标应可被理解，必要时配文字；M3 *Badges* | 状态点加 tooltip 和语义标签，无意义的装饰点去掉 | ⏳ |
| H7 | 便签 / 画布卡片的正文重复显示标题 | Things / Apple 备忘录：标题即首行时正文不再重复；HIG *Typography – hierarchy* | `previewWithoutTitle`：正文以标题（或被截断的标题）开头时去掉重复部分；只有一行时显示类型名 | ✅ `test/preview_dedupe_test.dart` |
| H8 | 右键菜单整层从屏幕左上角放大进入（缩放原点是整个屏幕而不是菜单），靠右 / 靠下翻转后更明显 | M3 *Menus*：菜单从触发点展开；HIG *Context menus* | 缩放只作用在菜单自身，原点随翻转方向取左上 / 右上 / 左下 / 右下；退出反向播放 | ✅ |

## 二、动效（进入与退出对称、可打断）

| # | 问题 | 依据 | 修复 | 状态 |
|---|---|---|---|---|
| M1 | 宽屏切换侧栏分区时，内容区先闪白再出现新内容（只有进入、没有退出） | M3 *Motion – Fade through*：旧内容先淡出，新内容再淡入，两段不重叠 | `MotionSwitch` 改为 Fade-through：前 35% 旧内容淡出，后 65% 新内容淡入 + 0.96→1 缩放 | ✅ `before-wide-switch-blank.png` → `after-wide-switch.png` |
| M2 | 返回时页面直接消失或只淡出，与推入不对称 | HIG *Motion*：返回动画应是进入动画的逆过程；M3 *Transitions* | 返回用同一曲线反向播放（时长 300ms，进入 450ms，符合 M3 退出短于进入） | ✅ `after-pop-exit.png` |
| M3 | 列表删除条目瞬间消失，下面的内容跳上来 | M3 *Motion – Lists*：移除项淡出并收起；HIG *Animation – 保持空间连续性* | `ExitTracker` + `CollapseOut`：淡出 + 高度收起；左滑删除不重复播放 | ✅（块列表）⏳ 任务列表、日历日程、回收站 |
| M4 | 转场中途返回是否可打断 | M3：用户操作优先，动画可中断 | 路由转场由 `AnimationController` 驱动，中途返回从当前进度反向播放（Flutter 路由原生行为，自定义转场未破坏） | ✅ |
| M5 | 软件渲染下 Xvfb 掉帧 | — | 测试环境限制，真机 GPU 渲染需另验 | 📝 |

## 四、点击区域与控件

| # | 问题 | 依据 | 修复 | 状态 |
|---|---|---|---|---|
| C5 | 玻璃背景上关闭状态的开关轨道几乎透明，看不出是开关 | WCAG 2.2 *1.4.11 Non-text Contrast* ≥ 3:1；HIG *Toggles* | 玻璃模式下关闭态轨道加深（浅色 35% 黑、深色 65% 灰） | ✅ |
| C1 | 首页 / 任务页筛选胶囊只有 28 高，触屏上容易点空 | HIG *Hit targets* 44×44pt；M3 48dp；WCAG 2.5.8 | 胶囊视觉仍 28 高，整行 44 高都可点（`FilterTab.hitHeight`）；图标按钮在触屏上本来就由主题扩到 48dp，桌面保持 32（Fluent 2 / macOS 鼠标尺寸） | ✅ `alignment_test.dart` |
| C2 | 返回图标显示成「楼房」形状 | HIG *SF Symbols*：返回统一用 chevron | 返回 / 关闭 / 侧栏统一 Cupertino 图标 | ✅ `before-back-glyph.png` |
| C3 | 任务筛选是描边 Chip，首页筛选是胶囊 Tab，同一种控件两种样子 | HIG *Consistency*；M3 *Chips*：同一用途用同一种控件 | 任务页改用首页的 `FilterTab` | ✅ |
| C4 | 桌面端 Esc 不能关闭二级页面 | Fluent 2 *Keyboard*：Esc 关闭当前层；macOS 同样 | 焦点树里没人处理 Esc 时逐级返回（对话框、菜单、搜索框自己的 Esc 优先），到首页不做任何事、不弹「再按一次退出」 | ✅ `task_dashboard_widget_test.dart` |
