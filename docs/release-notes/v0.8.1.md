# SyncNotes v0.8.1

v0.8.0 的修复版，修复了各端（Android、Windows、Linux、网页）的一批问题，重点是**数据安全、页面层级与动效、对比度和跨端一致性**。协议版本仍为 3，不需要迁移数据，服务器和客户端直接升级即可。存储仍是明文，没有加密；服务器脚本仍不会改防火墙规则。

完整问题清单见 [`docs/bugs-v0.8.1.md`](../bugs-v0.8.1.md)，设计审计（每条都对照 HIG / Material 3 / Fluent 2 / WCAG）见 [`docs/design-audit-v0.8.1.md`](../design-audit-v0.8.1.md)。

## 数据安全（所有端）

- **多设备同时修改不再丢内容**：以前两台设备同时改同一条笔记，后同步的一方会把另一方的修改静默覆盖。现在被覆盖的那一版会另存为「标题（冲突副本 月/日 时:分）」，放在原笔记旁边，App 和网页行为一致。
- **新建任务后直接返回，不再留下「未命名任务」**，也不会同步到其它设备。
- **夏令时地区的日期修正**：在欧美等有夏令时的地区，重复事件、订阅续费日、倒数日、「提前 N 天」提醒不会再重复或跳过一天，提醒时间也不会偏一小时。
- 任务进度遇到异常数据时不会再显示 NaN%。

## 服务器

- 登录加了失败次数限制：同一用户名 15 分钟内最多错 10 次，同一 IP 最多 60 次，超过后提示稍后再试。
- 两台设备同时注册同一个用户名时，后到的一方提示「用户名已存在」，不再报服务器内部错误。
- 一键恢复不再把所有附件读进内存，附件很大时小内存服务器也不会被系统强制结束。
- 修复恢复时两个附件 id 前缀相同可能互相串内容的问题。
- 密码校验不再占用同步线程，多人同时登录时其它设备的同步不会卡顿。

## App（Android / Windows / Linux）

- **页面切换不再文字重叠**：打开设置、回收站、任务等页面时，旧页面的文字会透过新页面露出来，开玻璃效果时最明显。现在新页面完整覆盖，旧页面同步后退并被裁掉，返回时动画完全对称。
- **宽屏切换分区不再闪白**：改为 Material 3 的「淡出再淡入」。
- **删除有退出动画**：笔记列表、任务列表、回收站里删除或恢复的条目会淡出并收起，不再瞬间消失、下面的内容跳上来。
- **右键菜单从点击位置展开**，不再从屏幕左上角飞进来。
- **对比度**：玻璃背景上的次要文字、占位文字、关闭状态的开关都加深到 WCAG AA；背景着色减淡，文字不再和背景图案混在一起。
- **返回图标**修复为标准的「‹」，不再显示成楼房形状。
- **日历**：标题固定为「日历」；今天和选中日期用圆形标记；新建按钮改为实色。日历是 SyncNotes 自己的，不读写系统日历、不申请日历权限。Android 关掉应用后也会按时提醒（使用普通本地通知，不申请精确闹钟权限，重启手机后自动恢复）。
- **任务页**：没有任务时不再显示一排 0；统计数为 0 时用灰色，只有真有逾期或风险时才显示红色或橙色；筛选样式与首页一致。
- **注册时需要再输入一次密码**，与网页版一致。
- **桌面端按 Esc 逐级关闭页面**；在首页按 Esc 不会有任何反应。
- 首页和任务页的筛选标签在触屏上可点范围扩大到整行高度；卡片正文不再重复显示标题。

## 网页版

- 浏览器不支持 WebGL 时不再整页灰底，会显示与 App 同色的渐变背景。
- 登录页改为与 App 相同的布局：应用图标、分组表单、主按钮，下面是「注册」「忘记密码」文字链接。
- 次要文字颜色加深，达到 WCAG AA 对比度。
- 注册后的恢复码弹窗不会因为点到背景而关闭，必须点按钮确认。
- 重连补同步时不再弹出一堆「新消息」提示。

## 测试

- 新增网页端到端测试（Playwright + 真实服务器）：注册、刷新后保持登录、两个浏览器实时同步新建与删除、回收站、任务与日历页面、密码错误提示。已加入 CI。
- 新增 App 测试：页面转场不重叠、冲突副本、空任务丢弃、Esc 逐级返回、注册确认密码、夏令时日期（CI 额外在纽约时区运行）。
- 新增服务器测试：登录限流、同前缀附件恢复。

## 需要在真机上确认

- Android：关掉应用后的日历提醒、重启手机后提醒是否恢复、120Hz 下的转场流畅度。
- Windows：高 DPI 下的玻璃效果与转场。
- 本次测试中，Linux 桌面版在虚拟显示器（软件渲染）上实际运行并截图，网页版在 Chromium 上测试。

## 已知问题（留到 v0.9）

- 登录令牌长期有效，不会因长时间不用而过期；修改密码会让其它设备的令牌失效。
- 日历「议程」视图删除条目时还没有退出动画。
- 首页玻璃布局和非玻璃布局仍是两套容器（子组件已经共用）。
- 自由画布还没有网格吸附。
