# SyncNotes v0.5.0：回收站、找回密码、服务器管理脚本、全平台交互规范

> 本版合并了 #6、#7、#8、#9（集成分支 `release/v0.5.0-dev`）。客户端和服务器要一起升级：旧客户端看不懂回收站，会把回收站里的项目当作普通项目显示。

## 新功能

### 回收站（#8）
- 删除不再直接硬删除，而是移入回收站：可以恢复、彻底删除、清空。服务器默认 30 天后自动清理（`--trash-retention-days` / `SYNCNOTES_TRASH_DAYS`，0 = 永不清理）
- 文件夹和页面带着子项一起进回收站、一起恢复；原父级已经不在时恢复到根目录，并给出提示
- 回收站有搜索、多选批量操作和空状态；入口在侧边栏和「设置 → 其他」

### 忘记密码与数据救援（#9）
- 注册时生成一次性恢复码（只保存哈希）。登录页「忘记密码？」可以用用户名 + 恢复码重置密码
- 「设置 → 账号」：生成 / 重置恢复码、修改密码、导出我的数据（zip：JSON + Markdown + 附件）
- 管理员命令 `syncnotes-server admin list-users / reset-password / export / backup`；脚本菜单「忘记密码 / 数据救援」和 `syncnotes-rescue.sh`
- 重置密码只改密码和登录令牌，块、附件、回收站和已读状态全部保留

### 服务器一键管理脚本（#7）
- `scripts/syncnotes-server.sh`：中文菜单 + 子命令，可以临时运行、后台运行、安装为 systemd 服务、更新（失败自动回滚）、卸载；会自动发现旧安装并迁移数据
- 服务器程序支持 `--version`

## 交互规范（#6 + 集成分支）

### Android
- **返回键**：原来按返回总是直接退出。现在逐级返回：先关对话框、菜单、抽屉、多选，再回到上一页，回到首页后"再按一次退出"；也支持预测性返回
- 编辑中按返回不会丢内容；恢复码对话框在勾选"已保存"之前按返回关不掉
- 状态栏 / 导航栏透明，图标颜色跟随浅色 / 深色主题
- 触屏可点区域至少 48dp（按钮外观不变）；按下有水波纹；长按菜单有触感反馈；拖动列表时收起键盘
- 通知权限：先说明用途，再请求系统权限（Android 13+）；点击通知会打开对应的内容
- 支持从其它应用分享文字和文件进来；消息、笔记、文件可以分享到其它应用
- 自适应图标，并支持 Android 13 主题图标

### 桌面（Windows / Linux）
- 记住窗口位置和大小；可以选择关闭窗口时最小化到托盘还是直接退出
- 快捷键：Ctrl+N 新建、Ctrl+W 关闭页面、Ctrl+F 查找、Ctrl+, 设置；Esc 可以关闭搜索和找回密码页
- 可以把文件直接拖进窗口上传
- 笔记可以"复制 Markdown"
- 悬停高亮只对鼠标生效，触屏上不会残留

### 全平台
- 200% 字号下不溢出（卡片、快速查找、设置、登录）
- 交互规范自查清单：`docs/qa/platform-conventions-audit.md`
