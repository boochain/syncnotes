# SyncNotes 1.3.0

这一版把上次列出来的缺口补上了。改密码和分享需要新的服务端，请把服务器也换成这个版本。旧笔记还能打开。

- 表格、往正文里放图片、手写后放进笔记、查找并替换、这篇笔记的历史版本
- 笔记颜色、智能文件夹、图谱、把笔记拖进文件夹、手动顺序
- 安卓：系统分享进来、语音转文字、拍照扫描、桌面小组件和快捷方式「写一条」
- Windows 托盘菜单可以新建笔记。其他系统用 Ctrl+N
- 设置里可以剪藏一个网址，也可以把剪藏书签放进浏览器
- 应用锁。修改登录密码时，笔记和文件会先用新密码重新加密
- 两台设备同时改同一篇，会问你留这台、留另一台，还是两边都留
- 提醒到点会在软件里响；安卓还会出通知
- 分享给别人用的是另一把分享密码，服务器只存密文。对方在设置里接收
- 评论写在笔记里，跟着你的账号同步。分享出去的是当时的一份副本

语音转文字和拍照扫描在手机上。电脑上扫描会改成选一张图片，语音会提示改用手写。
