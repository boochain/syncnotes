# SyncNotes v0.7.1

本版重点修复 0.7.0 的页面切换体验与收件箱布局，并新增优先级排序与完成标记。协议未变，客户端可直接覆盖升级。

- **不透明页面卡片弹出转场**：打开/关闭笔记编辑器、页面、文件夹、设置等子页时，改为不透明页面卡片平滑弹出盖住主页（附柔和暗幕），去掉逐帧全屏模糊与透明叠层，消除文字叠加与动画卡顿。
- **底部栏常驻消息框 + 右侧独立圆形「+」**：取消底部 4 图标坞，消息发送框常驻底部方便随时发消息；新建按钮作为独立圆形按钮放在消息发送框右侧。
- **顶栏与搜索布局整理**：软件标题「SyncNotes」居中，连接状态显示在标题正下方；顶栏操作按钮统一收拢到左侧；搜索按钮移到顶部四个分类切换项的右侧。
- **优先级排序与完成标记**：列表与便签按「未完成优先 → 优先级（紧急 / 重要 / 待办 / 灵感 / 备忘 / 默认）→ 创建时间」排序；支持一键勾选完成标记（卡片、便签、右键菜单与笔记编辑器均支持），已完成项自动归入底部的独立「已完成」分区，未完成项始终保持在最前。
