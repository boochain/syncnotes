# SyncNotes v0.7.0

这一版主要是界面大改。服务器协议没变，旧服务器仍能用，建议客户端和服务器一起更新。

- 液态玻璃重做。折射、高光边缘和色散边更自然，设置里的透明度、折射率、画质滑块拖动即时生效。
- 新增流体动态背景，深浅色各一套配色，可以在「设置 → 外观」里开关。
- 收件箱新增便签画布。便签可以自由拖动和叠放，分 6 种颜色，右上角一键整理，位置和颜色会同步到其他设备。窄屏自动变成网格。也可以切回普通列表。
- 笔记编辑器去掉了输入卡顿。点开笔记直接编辑，宽屏左边编辑右边预览，支持 Ctrl+B、Ctrl+I、Ctrl+S。
- 侧边栏、顶栏和底部快速发送栏改成悬浮的玻璃胶囊。页面切换、搜索展开使用失焦到对焦的过渡。
- 设置页和相关测试一并整理。
