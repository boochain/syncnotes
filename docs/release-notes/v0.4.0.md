# SyncNotes v0.4.0：统一尺寸、字体和颜色

## 参考的设计
- **AppFlowy**（只参考数值和模式，没有复制代码）：顶栏 44、侧边栏分组 32、页面树行高、间距和圆角刻度、正文 14/20 与说明 12/18、编辑器行高 1.5、标题递增、封面和页面图标尺寸
- **Notion**：侧边栏 + 页面布局、封面与压住封面下沿的图标、斜杠菜单、Ctrl+K 快速查找、悬停手柄
- **Apple HIG**：系统灰阶和唯一强调色 systemBlue、开关、分段控件、分组表单、SF Symbols 风格（Cupertino）图标

## 统一的设计规则
- **高度刻度**：28 / 32 / 36 / 44 / 56，同一行的元素等高、垂直居中；发送栏的 + / 输入框 / 发送同为 36
- **字体**：一套字体栈，5 级字号（12 / 14 / 14 中等 / 16 / 20），只用 400 / 500 / 600 三种字重；编辑器另有 36 / 30 / 24 / 20 / 16 的标题层级；emoji 与文字基线对齐
- **颜色**：中性灰阶 + 唯一强调色；代码块、提示框、行内代码统一使用中性底色；封面改为四种低饱和色调
- **玻璃**：只用于浮动界面（斜杠菜单、快速查找、格式工具栏），背景保持纯色
- 详细说明见 `docs/design-system.md`
