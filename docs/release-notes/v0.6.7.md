# SyncNotes v0.6.7

协议没有变。连接更稳，建议把服务器也换成 0.6.7；只换客户端也能减轻断线。

- 页面切换改成不透明淡入。不再用会把上一页露出来的滑动和预测返回，浮层也不再把背景再画一层，高分屏上不会叠出两套界面。
- 心跳改成 8 秒一次，避免移动网络把空闲连接拆掉。正在握手时切回前台不会把连接掐掉重来。安卓通知在真正连上之前写「正在连接」，不再一直写「正在重连」。
- 服务器不再把数据库暂时锁住当成登录失效。这条连接每 15 秒发一次保活，旧客户端不用改协议。
- Windows 开机自启不再给程序路径多加一对引号，已经打开但没生效的会在下次启动时改回来。托盘图标在窗口显示之后才注册，并再试一次；「关闭到托盘」打不开托盘时会提示，不再假装已经生效。
