# SyncNotes v0.8.0

把动效与流畅度修复、任务仪表盘、日历、一键同步 / 备份 / 恢复和独立网页版合并成一个版本发布。协议版本仍为 3，旧数据直接可用。服务器和客户端建议一起升级：一键恢复需要 v0.8.0 服务器（`/health` 的 `features` 含 `backup`）。存储仍是明文，没有加密；服务器脚本仍不会自动改防火墙规则。

## 新功能

### 动效、顶栏、玻璃与流畅度

- **页面转场重做**：笔记、页面、设置、任务、日历等子页统一用一套动效：Material 3 Emphasized 的时长与缓动（进入 400ms 减速，返回 300ms），加 iOS 式覆盖推入。新页从侧边整页滑入，旧页只做 30% 视差和压暗。不再“闪一下”，打开笔记时正文也不会和主页文字叠在一起。系统开了“减少动态效果”时直接切换。选型依据见 [`docs/motion.md`](../motion.md)。
- **手机顶栏**：头像在最左，设置在最右，标题和连接状态居中。第二行是分类、搜索、查看方式，查看方式在搜索右边。
- **玻璃与流体背景全页面可见**：所有子页（含笔记编辑器、任务、日历、设置、回收站）都透出流体背景，不再被不透明底色盖住。折射率滑块在高分屏手机和 Windows 高 DPI 上也会改变边缘色散、高光和光晕。
- **流畅度**：Android 请求显示器最高刷新率（120Hz 机型可跑 120fps），并显式开启 Impeller。流体背景按画质档位限帧，列表卡片改用轻量描边，不再每行一层模糊。

### 任务仪表盘

- 侧边栏新增「任务」（显示逾期数量）。任务可以放在收件箱或文件夹里，`Ctrl+K` 能搜到。
- 每个任务可设：状态、重要程度（无 / 低 / 中 / 高 / 紧急）、旗标、里程碑、开始 / 截止 / 完成时间、备注。
- **自定义进度**：自己列出进度组成项并给每项设权重。组成项可以是勾选项、百分比或子任务。也支持均分和手动百分比两种模式。
- **子任务**有自己的起止时间和进度，按权重滚入父任务。已取消的子任务不计入。全部完成后可以自动完成父任务。
- 参考 Things、滴答清单、Todoist、Asana、Linear 等产品加入的细节：今天 / 即将 7 天 / 逾期 / 进行中 / 有风险 / 已完成等智能列表，进度环，以及按起止时间估算的“有风险”健康状态。设计说明见 [`docs/task-dashboard.md`](../task-dashboard.md)。

### 日历、会员订阅与倒数日

- 侧边栏新增「日历」，有月 / 周 / 年 / 议程视图，带农历显示。
- **会员订阅**：起止日期、周期（单周 / 单月 / 单季度 / 单年 / 自定义 / 一次性）、是否自动续费、金额、试用期和状态。会算出下次扣款日、每月折合花费，并提醒续费。
- **重要日期与倒数日**：可以每年重复（如生日），显示“还有 N 天 / 已经 N 天”，可选显示年龄，可置顶。
- 带开始或截止日期的任务会叠加在日历上，点一下进入任务编辑页。日历条目不进收件箱，也不计入未读。说明见 [`docs/calendar.md`](../calendar.md)。

### 一键立即同步、备份与恢复

入口在「设置 → 备份与同步」，说明见 [`docs/backup-restore.md`](../backup-restore.md)。

- **立即同步**：把本机所有未同步的修改和附件增量上传到服务器，已同步过的内容不会重传。
- **备份**：把服务器上的内容和本机还没同步的修改一起打包成 zip，你能看到的都会进备份。任务、日历条目、回收站、已读状态和附件都在内。离线时退回打包本机缓存。
- **恢复**：把备份 zip 上传到当前登录的账号，账号还原成备份时的状态。恢复前会先让你保存一份当前数据，服务器也会另存一份安全备份。密码和恢复码不变，其他已连接的设备会自动重新同步。可以用来迁移账号或换服务器。
- 服务器端新增 `POST /api/restore`；救援脚本新增 `export` / `restore` 子命令（Linux `syncnotes-rescue.sh`、Windows `syncnotes-server.ps1`）。

### 独立网页版

- 新增 `web/`，是独立的 Vite + React 静态站点。它直接连接已部署的 SyncNotes 服务器，和服务器分开部署，服务器不需要改动。部署方法见 [`docs/web-client.md`](../web-client.md)。
- 支持：登录 / 注册 / 恢复码找回、实时同步与离线队列、消息、笔记、便签画布、页面、文件分片上传下载、文件夹、回收站、流体背景与玻璃。
- **任务**：可以查看列表、筛选（未完成 / 逾期 / 已完成）、加权进度、组成项和子任务，还能勾选完成。勾选时保留原始类型和所有其他字段。
- **日历**：只读。可以看近 60 天日程（含带日期的任务）、会员订阅（下次扣款、每月折合）、重要日和倒数日。

## 已知限制

- 网页版不能新建或编辑任务的组成项和权重，也不能新建或编辑日历条目，请在桌面或手机客户端操作。网页版没有一键备份和恢复。页面编辑器是简化版。还没有在真实服务器上做浏览器端到端测试。
- 第三方玻璃库的真实 IOR 厚度采样只在 DPR < 2.5 时开启，否则会多画一层。高分屏上的“折射”效果来自边缘色散和高光，不是透镜采样。
- 日历暂不支持按农历重复（只显示农历），也没有小组件、系统日历导入导出和自动汇率。Android 使用非精确提醒，回到前台时补发。
- 备份 zip 不加密，请自行妥善保存。

## 需要真机验证

本次在 CI 和本地跑了服务器、Flutter 和网页版的自动化测试，但没有真机或模拟器。请重点试这些：

- Android 120Hz 机型的实际帧率和滑动流畅度，以及 Impeller 下的玻璃效果。
- Windows 高分屏（150% / 200% 缩放）下的玻璃、折射率滑块和顶栏布局。
- Android 预测性返回手势：任务详情、日历编辑页能逐级返回，根页面按两次退出。
- 大体积备份（几 GB 附件）的打包、分片上传和恢复耗时，以及恢复后其他设备的重新同步。
- 网页版在 nginx / Caddy 反向代理（含 WebSocket）下的登录和实时同步。

## 升级

- 服务器：`sudo ./syncnotes-server.sh update ./syncnotes-server-v0.8.0-linux-x86_64.tar.gz`（失败自动回滚），Windows 用 `syncnotes-server.ps1` 的更新菜单。
- 客户端直接覆盖安装。旧客户端仍能同步，但会把任务和日历显示成“未知类型”。
