# SyncNotes v0.6.12

协议没有变。客户端和服务器可以分开升级。超过 100 MB 的文件仍需要 0.6.11 或更新的服务器。

- 选文件可以一次选多个，按队列一个一个传，不用等上一个结束才能选下一个。进度刷新不再重画整个侧边栏。
- 文件夹可以设置图标，列表和文件夹页会显示这个图标。
- 外观可以选背景色（默认、海蓝、暮色、纸色、墨色），液态玻璃可以调透明度。高分屏仍然只用模糊，避免两层叠在一起。
- 页面切换在不透明底色上淡入并轻微上移。返回更快，不会把上一页透出来。
- 登录过的服务器会记住，登录页可以直接点。没写协议时，域名自动用 https，IP / localhost / .local 自动用 http。
- 设置里说明了指纹是什么、会影响什么，以及哪些路径是密文、哪些是明文。
- 服务器脚本新增 `proxy 域名`，打印 Caddy 和 Nginx 反代配置，不安装、不改防火墙。
