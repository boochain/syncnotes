# SyncNotes v0.6.6

协议没有变。已经在跑 0.6.1 及以后服务器的话，只换客户端即可。

- Windows 托盘图标改为系统能读的 ico（含 16 到 64 像素）。以前的图标是压进 ico 的 PNG，高分屏上托盘是空的，点关闭等于直接退出。
- 「启动时最小化」和「关闭到托盘」在没有托盘图标时不再把窗口藏起来。开机自启不再强制 `--hidden`，是否最小化只看「启动时最小化」。
- 安卓后台通知改成状态栏可见的普通优先级，并用单色小图标。从最近任务划掉后服务继续跑。第一次会询问是否忽略电池优化。
- Linux 若仍然没有托盘图标，需要安装 `libayatana-appindicator3-1` 后重新打开。
