# SyncNotes v0.3.0：重做界面

## 设计
- **以 Apple HIG 为统一基础**：所有平台使用同一套系统色、字号层级（中文使用免费字体回退）、Liquid Glass 材质、间距、圆角、SF Symbols 风格图标和弹簧动效
- **布局与交互照 Notion**：侧边栏、封面 + 压住封面下沿的页面图标、Notion 字号比例、悬停手柄、斜杠菜单、快速查找、行内格式工具栏
- 少量借用 Material 3（色调调色板、时长令牌、Android 预测性返回、状态层）和 Fluent 2（间距阶梯、快捷键提示、亚克力回退参数），每一处的原因写在重写后的 `docs/design-system.md`

## 修复的视觉问题
- 页面图标被封面遮住：现在压在封面下沿约 45%，完整显示在最上层，和标题对齐并留出间距
- 编辑器里显示原始 Markdown 标记：现在所见即所得，只在光标所在片段淡显标记
- 中文斜体看起来像删除线（合成倾斜的字互相重叠）：中文强调改为点状下划线，西文仍用斜体
- 收件箱和快速查找的摘要里出现 `**`、`` ` ``、链接地址等标记：现在显示纯文本
- 封面渐变过于艳丽：换成低饱和预设，深色模式下再压暗
- 提示框底色太深、太灰：改为 Notion 的浅暖灰（深色为白 6%）
- 引用字号比正文小：改为与正文同字号
- 格式工具栏是一条贴底的灰条：改为浮动的玻璃胶囊
- 斜杠菜单三个标题命令图标相同、深色下图块是纯黑方块：改为 H1/H2/H3 字形和半透明图块
- 登录页是深色描边的 Material 输入框：改为 HIG 分组表单、应用图标和大号主按钮
- 设置页在宽屏下开关离标签太远：内容限宽居中；打开设置时侧边栏同时高亮"收件箱"和"设置"：现在只高亮"设置"
- 收件箱标题栏和侧边栏重复显示"在线"状态；空页面显示"空页面"字样；摘要句号后又接分隔点（"。 ·"）
- 未读卡片的粗边框和灰底、消息标题与正文重复显示、Material 风格的 ⋮ 图标、实心灰色发送栏
- 深色模式下关闭状态的开关轨道几乎看不见：改用 HIG systemFill
- 窄屏下块手柄和标题不对齐；页面标题在窄屏上过大（缩到 32）

## 修复的功能问题
- 宽屏打开设置后点击侧边栏页面没有反应（设置页没有关闭）
- `2 * 3 * 4` 这样的算式被当成斜体，星号被隐藏
- 文件夹条目重新显示项目数
