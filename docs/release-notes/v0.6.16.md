# SyncNotes v0.6.16

协议没有变。客户端和 0.6 服务器可以分开升级。建议同时更新服务器：文件夹循环、永久删除和改密踢线这几处只在新服务器上生效。

- 可以选一张本地图片当背景，并调节遮罩深浅。液态玻璃增加折射率，以及标准 / 高阶折射 / 轻量毛玻璃三档。
- 侧边栏可以一键切换浅色、深色、跟随系统，也可以收起（Ctrl+\）。文件夹和页面图标改成统一的矢量图标，不再用 emoji。
- 上传和下载分开排队：一路上传、两路下载。速度用滑动平均，短暂断线会自动重试两次，取消会立刻断开。
- Windows 关闭后会真正进托盘；从托盘恢复时马上探测连接。Windows 和 Linux 的原生标题栏会跟着浅色 / 深色走。退出时会放开单实例锁。
- 永久删除后的内容不会被离线旧编辑复活。两个设备互相把文件夹拖进对方时，服务器会打断循环，不再死循环。改密码会立刻踢掉其他设备，当前这次登录保留。彻底删除时连页面里的图片和校验文件一起清掉。导出 Markdown 能写出图片，也不会被坏掉的父子关系卡死。
- Windows 服务器包带上 `syncnotes-server.ps1`（启动、开机任务、重置密码、导出、备份）。Linux 包继续附带救援脚本。
