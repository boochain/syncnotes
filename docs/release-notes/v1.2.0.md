# SyncNotes 1.2.0

这一版补的是操作之后软件怎么回话。服务器仍然不用换。

- 划到回收站可以撤销。彻底删除、清空回收站、退出登录都会先问一句
- 列表上能看到连上了没有、上次同步是什么时候。失败可以重试，也可以下拉再同步
- 宽屏选中笔记后在右边写，不用离开列表
- 长按：置顶、移动、复制、丢进回收站。可以多选后一起处理
- 每篇显示多久以前改过。待办有一个总列表
- 文件夹能改名，也能选一个图标，旁边有笔记数量
- 编辑时输入 `/` 可以选择待办、标题、日期。可以在这篇里查找，点标题跳过去
- 附件可以拿掉。设置里可以导出全部 Markdown，也可以导入一篇
- 登录可以显示密码。密码太短会告诉你：这是钥匙，丢了找不回
