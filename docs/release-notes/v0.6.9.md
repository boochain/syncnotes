# SyncNotes v0.6.9

协议没有变。

- 服务器的数据库、加密密钥和上传的文件不再放在解压出来的版本目录里。普通用户是 `~/.local/share/syncnotes`，用 root 跑是 `/var/lib/syncnotes`，Windows 是 `%ProgramData%\SyncNotes`。当前目录里已有的 `syncnotes.db` 会在第一次启动时复制过去，原文件保留。用 `syncnotes-server.sh` 安装的仍然是 `/opt/syncnotes/data`，不受影响。
- 客户端的登录和本地缓存本来就在系统用户目录，不在程序目录里。设置里现在能看到这个路径。
