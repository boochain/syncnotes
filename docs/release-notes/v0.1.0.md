## SyncNotes v0.1.0 — 首个版本

### 下载

| 文件 | 说明 |
|---|---|
| `SyncNotes-windows-x64.zip` | Windows 客户端（解压运行 `syncnotes.exe`） |
| `SyncNotes-linux-x64.tar.gz` | Linux 客户端 |
| `SyncNotes-android.apk` | Android 客户端 |
| `syncnotes-server-linux-x86_64` | 服务器（Linux x86_64，静态链接） |
| `syncnotes-server-linux-aarch64` | 服务器（Linux ARM64） |
| `syncnotes-server-windows-x86_64.exe` | 服务器（Windows） |
| `SHA256SUMS.txt` | 校验和 |

### 功能

- 消息 / 笔记(Markdown) / 文件 / 文件夹 四种块，可扩展类型系统
- 多设备实时同步（WebSocket），离线编辑排队并在重连后重放
- 每个块可选"按设备已读"或"全局已读"
- 用户名密码登录 + 令牌自动登录
- 桌面托盘常驻、右下角小窗口；Windows/Linux 登录自启
- Android 前台服务保持连接 + 本地通知推送，可开机自启
- 局域网直连 + mDNS 发现

### 已知限制

- APK 使用调试签名（可直接安装，但不能从应用商店更新）
- Windows / Android 客户端尚未在真机上做完整人工测试，见 README
- 冲突处理为整块"最后写入者获胜"，暂不支持同一笔记的字符级合并
