# SyncNotes v0.7.2

基于全尺寸实机界面视觉自检完成的细节打磨版，协议未变，客户端可直接覆盖升级。

- **修复窄屏顶栏标题重叠**：收紧左侧悬浮按钮胶囊的触控占位并按可用宽度动态居中，360px / 390px 手机与 400px 桌面托盘小窗下左侧按钮与居中标题 `SyncNotes` 彻底分离不重叠。
- **修复搜索与加号圆形按钮比例**：统一收缩多余外边距，搜索圆形按钮与四个分类切换胶囊严格等高（36px），底部右侧独立圆形 `+` 按钮与常驻消息发送框严格等高（46px）。
- **优化搜索框与玻璃高光细节**：浮动搜索胶囊内的输入框去掉突兀的方形外边框；去除小圆形按钮顶部的高光白斑，整体更通透协调。
- **优化窄屏便签卡片与侧边栏状态**：精简便签卡片时间戳文案与内边距，双列手机卡片时间不再截断；侧边栏头部只保留紧凑连接状态，不再被挤压省略。
