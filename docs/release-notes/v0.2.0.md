# SyncNotes v0.2.0

## 新功能：Notion 式页面编辑器
- 块编辑器：段落、一/二/三级标题、项目符号 / 编号 / 待办列表、折叠块、引用、提示框、代码块（语法高亮）、分割线、图片、子页面
- 行内格式：粗体、斜体、行内代码、删除线、链接（快捷键与浮动工具栏）
- 输入 `/` 打开斜杠菜单（支持中文、英文、拼音首字母搜索）；行首 Markdown 快捷方式自动转换
- 回车拆分、退格合并、Tab 缩进、方向键跨块移动、拖动排序、撤销 / 重做
- 嵌套页面、面包屑、页面图标与封面
- 侧边栏页面树、Ctrl+K 快速切换器（搜索标题与正文）、收件箱分类筛选与空状态
- 同步粒度细化到块：每个内容块独立同步，多设备同时编辑同一页面的不同块不会冲突
- "新建 → 笔记"现在会创建页面；旧版 Markdown 笔记仍可查看和编辑

## 新界面：Liquid Glass + 设计系统
- 使用开源库 [liquid_glass_widgets](https://pub.dev/packages/liquid_glass_widgets) 1.13（着色器折射、模糊、高光，支持 Windows / Linux / Android）实现 Apple 风格玻璃面板；背景为流动渐变
- 设计令牌全部取自 Apple HIG、Material 3、Fluent 2，并按平台适配：Windows 使用 Fluent 2，Android / Linux 使用 Material 3。说明见 `docs/design-system.md`
- 浅色 / 深色 / 跟随系统，弹簧动画，响应式布局（宽屏显示侧边栏，窄屏使用抽屉）；桌面端可一键在托盘小窗与大窗口之间切换
- 设置环境变量 `SYNCNOTES_GLASS=0` 可改用轻量毛玻璃效果

## 修复
- 合并或撤销后，获得焦点的块显示旧文本（输入框没有刷新模型内容）
- 斜杠菜单被玻璃面板裁剪，靠近底部时显示不全（现在渲染在根浮层，空间不足时向上弹出）
- 主题的输入框描边泄漏到编辑器的无边框输入框
- 打开页面时在构建阶段标记已读，触发 setState 异常
- 托盘窄窗口里，连接状态标签在标题栏中溢出
- 搜索结果中混入页面内容块（text 块不再出现在收件箱）
- liquid_glass 的 `adaptiveQuality` 基准测试在软件渲染（Mesa llvmpipe）下调整窗口尺寸时崩溃，已关闭该选项
