## SyncNotes v0.1.1 — 打包修正 + 全面 Bug 修复

### 下载（所有文件都有扩展名）

| 文件 | 说明 |
|---|---|
| `SyncNotes-windows-x64.zip` | Windows 客户端，解压后运行 `SyncNotes\syncnotes.exe`（已附带 VC++ 运行库） |
| `SyncNotes-linux-x64.tar.gz` | Linux 客户端，解压后运行 `SyncNotes/syncnotes` |
| `SyncNotes-android.apk` | Android 客户端 |
| `syncnotes-server-v0.1.1-linux-x86_64.tar.gz` | 服务器 Linux x86_64（含 README 与 deploy 配置） |
| `syncnotes-server-v0.1.1-linux-aarch64.tar.gz` | 服务器 Linux ARM64 |
| `syncnotes-server-v0.1.1-windows-x86_64.zip` | 服务器 Windows |
| `SHA256SUMS.txt` | 校验和 |

### 修复

**打包**
- Linux 服务器之前是无扩展名的裸文件 → 现在打包为 `.tar.gz`（保留可执行权限），Windows 为 `.zip`，并附带 README 和部署配置
- Windows 客户端缺少 VC++ 运行库，干净系统上可能无法启动 → 已随包附带

**同步可靠性**
- 网络"看似在线实际已断"时发出的修改会丢失 → 所有修改在服务器确认前都保留在待发送队列中，重连后自动重发
- 切换网络等导致的半开连接无法察觉 → 增加心跳超时检测，自动重连
- "清除本地缓存"会把未同步的修改一起删掉 → 现在保留未同步内容
- 退出登录时若有未同步修改会静默丢失 → 增加确认提示
- 退出登录后令牌在服务器上仍然有效 → 新增 `/api/logout`，退出时吊销令牌
- 新版本客户端创建的未知块类型经过服务器后被改成 `unknown`，数据丢失 → 服务器原样保存类型

**界面 / 功能**
- 可以把文件夹移动到它自己的子文件夹里，导致整组内容消失 → 已禁止
- 父文件夹被删除或尚未同步的块完全不可见 → 现在显示在根目录
- 文件夹图标颜色与背景相同几乎看不见 → 修正
- 标题截断可能把 emoji 截成乱码 → 按字符截断
- 新建文件夹 / 重命名对话框按回车无反应 → 回车即确认
- "关于"等系统对话框显示英文 → 启用中文本地化
- 关闭笔记编辑器时可能触发框架异常 → 修正保存时机
- 支持部署在反向代理子路径下（如 `https://host/notes`）

**安全**
- 下载的文件名来自其他设备，带 `../` 时可能写到下载目录之外 → 文件名清理（同时处理 Windows 非法字符和保留名）
- 服务器校验块类型和 id 格式

**桌面端**
- 系统没有托盘时点关闭会把窗口隐藏且再也找不回来 → 无托盘时关闭即退出，启动时也不会隐藏
- 重复启动会出现两个托盘图标和两个连接 → 单实例：再次启动只会唤出已有窗口
- 从托盘退出时可能丢失最后一次本地缓存写入 → 退出前先写完缓存
- 连接失败时日志中出现"未处理异常" → 已处理

**Android**
- 后台服务中请求通知权限会失败 → 只在前台界面请求
- 开启"开机自启"但未开启前台服务时实际不会启动 → 开启自启时自动开启后台连接
