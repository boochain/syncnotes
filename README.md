# SyncNotes 1

自己部署的多设备笔记。正文和文件在离开这台设备之前加密，服务器只保存密文。

这是从零重写的协议 1。它**不能**连接 0.6 的服务器，也不能打开 0.6 的本地库。旧数据导入还没有做。

## 客户端

- 登录 / 注册。同一密码在每台设备上推出同一把钥匙，用来解开笔记和文件。
- 文件夹、标签、置顶、全文搜索、排序
- Markdown：标题、列表、待办、引用、代码、预览，点待办可以勾上
- `[[标题]]` 链接和反向链接，今日笔记，会议 / 待办 / 日记模板
- 回收站里可以恢复或彻底删除
- 和人的来回：划掉可以撤销，彻底删除和退出会先问一句，同步状态写在列表上面，失败可以重试
- 表格、图片、手写、扫描、语音（安卓）、提醒、笔记颜色、图谱、智能文件夹、历史版本、查找替换、评论
- 应用锁、修改密码会整库重加密、两台设备改同一篇时让你选、用分享密码把一篇笔记给别人
- 把文件拖进笔记、粘贴图片、拖着手把给笔记排序、把文件夹拖进文件夹。安卓提醒在软件关掉后也会响
- 宽屏左边列表、右边直接写。长按可以置顶、移动、复制。多选后一起丢进回收站
- 待办汇总、文件夹可以改名和图标、输入 `/` 插入标题和待办、在这篇笔记里查找、导入导出 Markdown

- 附件加密后上传。进度按已经写进网络的字节走。等服务器确认时显示「确认中」。失败留在列表里，写出原因。
- 桌面：放大 / 缩小会先取消最大化，并且一定换成另一个尺寸。Windows 关闭按钮收到托盘。
- 外观可以选背景（默认、海蓝、暮色、纸色、墨色）、卡片透明度和字号。窗口本身不透明，避免页面叠在一起。
- 一次可以选多个文件，排队上传。设置里可以把本机缓存再传给服务器。
- Ctrl+K 按标题或正文跳到一篇笔记。
- 服务器有指纹。指纹只用来认出这台数据库，不是密码。设置里写了哪些内容是密文、哪些是明文。
- Windows 可以关掉「关闭窗口时收到托盘」。

## 服务器

一个可执行文件，外加一个 SQLite 和一个文件目录。

```bash
./syncnotes-server --bind 0.0.0.0:7700 --db /var/lib/syncnotes/syncnotes.db --files-dir /var/lib/syncnotes/files
```

没写 `--db` 时，数据放在 `~/.local/share/syncnotes`（Windows 是 `%LOCALAPPDATA%\SyncNotes`），不放在程序目录里。

`GET /health` 返回协议版本，以及这台数据库的指纹 `id`。指纹存在数据库里，重装或换库会变。

环境变量和以前的安装脚本兼容：`SYNCNOTES_BIND`、`SYNCNOTES_DB`、`SYNCNOTES_FILES`、`SYNCNOTES_ALLOW_REGISTER`。

## 限制

- 单篇笔记密文上限约 1 MB。单个文件上限 4 GB。
- 没有多人同时编辑，没有局域网自动发现，也还不能导入 0.6 的旧库。搜索在本机进行，因为服务器看不到正文。
- 语音转文字和系统分享在安卓上。电脑上的提醒只在软件开着时响。
- 反代示例：`sudo ./syncnotes-server.sh proxy 你的域名`，会打印 Caddy 和 Nginx 配置，不安装、不改防火墙。
